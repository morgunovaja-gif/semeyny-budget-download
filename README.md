# Семейный бюджет — скачать для Android

Приложение для учёта семейных расходов и доходов: чек по фото сам раскладывается по категориям, расходы можно надиктовать голосом, вся семья видит общий бюджет.

## ⬇️ [Скачать приложение (APK)](https://github.com/morgunovaja-gif/semeyny-budget-download/releases/latest/download/semeyny-budget.apk)

## Как установить

1. Нажмите на ссылку выше с телефона — начнётся скачивание файла `semeyny-budget.apk`.
2. Откройте скачанный файл.
3. Если телефон спросит, разрешить ли установку из этого источника, — разрешите.
4. Если Google Play Защита предупредит о неизвестном приложении, нажмите «Всё равно установить»: так бывает со всеми приложениями не из Play Market.
5. Откройте «Семейный бюджет», зарегистрируйтесь и нажмите «Присоединиться по коду» — вставьте приглашение, которое вам прислали.
